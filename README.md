# Enterprise RAG Knowledge Assistant

A production-oriented Retrieval-Augmented Generation (RAG) system that allows enterprises to chat with internal documents using Large Language Models.

## Features
- PDF and document ingestion
- Vector database storage
- Semantic search
- Retrieval-Augmented Generation
- Streamlit chat interface
- Multi-document support
- Source citation

## Tech Stack
- Python
- LangChain
- OpenAI
- ChromaDB
- Streamlit
- Hugging Face Embeddings

## Architecture
1. Upload enterprise documents
2. Chunk and embed text
3. Store embeddings in vector DB
4. Retrieve relevant chunks
5. Generate grounded responses
